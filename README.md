# הכלים של דוד

כלים לקלוד קוד, למי שבליווי.

## איך מתקינים

פותחים את קלוד קוד בתיקייה שלך וכותבים לו:

> תתקין לי את הסקאוט מ-github.com/suhsnkl1-max/david-tools

או מדביקים את השורה הזו:

```
/plugin install content-scout --marketplace suhsnkl1-max/david-tools
```

זהו. הוא מתקין לבד. בפעם הראשונה שתכתבי "תסרוק לי רעיונות" הוא יעזור לך לחבר את הכרום.

## לעדכן

כותבים לו: "תעדכן את הכלים של דוד".

## מה יש כאן

**סקאוט** (`content-scout`): את אומרת נושא, והוא נכנס דרך הכרום שלך לאינסטגרם, טיקטוק ושורטס, מחפש, פותח סרטונים, ומחזיר שתי רשימות: סרטונים שעקפו את הרגיל של היוצר שלהם, וסרטונים שפשוט עשו הכי הרבה. כל אחד עם קישור, המספרים האמיתיים, והשלד שאפשר לקחת ממנו.

הוא רק קורא. לא עושה לייק, לא עוקב ולא מגיב. כל מה שהוא שומר נשאר אצלך במחשב, בתיקייה `scout/`.
